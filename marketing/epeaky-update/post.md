## Post

Epeaky has screen sharing now. Share your screen in a voice room and it's encrypted just like the chat, so the server only ever passes along scrambled frames it can't look at. One person shares at a time, and the den's mods can stop it if they need to.

The other thing we've been working on: you can hand the setup to your AI agent. Tell it which server you already have and which domain you want to use, and it checks everything first: the machine, the ports, whether your domain actually points there. Then it tells you what it's about to do and waits for a yes before touching anything. It won't buy you a server or mess with your DNS. That part stays with you.

On Claude Code there's a skill for it. On Claude Desktop or anything else that speaks MCP, it's epeaky-host-mcp, which just went up on the official MCP registry.

We also redid the site, so you can finally see what the app looks like before you install it: epeaky.zyn-network.com
