# Cave Collection Z

Static launch site for the first 4,444-piece Cave Collection Z release.

```sh
npm run edges
npm start
```

The displayed specimens are Mole 0102, Owl 0057 and Moth 0051, shown as their
original art since 26 Sep 2026. Before the reveal they were black shadow
renders with rim-light edge masks (`assets/*-shadow.png`, `*-edge.png`, made
by `npm run edges`); the masks' black fill would cover the art, so the cards
now carry only the foil light for each effect.
